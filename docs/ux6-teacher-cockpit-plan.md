# UX-6 — Teacher Cockpit

Дата плана: 01.08.2026

## Цель релиза

Превратить набор функциональных разделов Tutor Assistant в единое операционное рабочее пространство преподавателя. Интерфейс должен постоянно отвечать на четыре вопроса:

1. какой ученик и какое занятие находятся в текущем контексте;
2. на каком этапе жизненного цикла находится занятие;
3. какие события требуют решения преподавателя;
4. какое действие логично выполнить следующим.

Целевая версия: `0.23.0`.

## Объём UX-6

### 1. Семантическая маршрутизация

- Ввести `AppRoute` вместо прямой зависимости навигации от числовых индексов `QTabWidget`.
- Создать единый реестр маршрутов с идентификатором, заголовком, группой, иконкой, сочетанием клавиш и legacy-индексом.
- Сохранить совместимость с существующими вызовами `_go_to(index)`.
- Добавить API `navigate(route)` и сигнал изменения маршрута.
- Проверять допустимость маршрута перед переключением страницы.

### 2. Экран «Сегодня»

- Добавить отдельную страницу рабочего пространства без изменения индексов существующих восьми вкладок.
- Показывать следующее занятие, время до начала, тему, предмет и основное действие.
- Показывать сводку недели: активные ученики, занятия и плановую выручку.
- Показывать незавершённые действия и текущие фоновые процессы.
- Добавить блок «Продолжить работу» для активного занятия.
- Добавить быстрые переходы к расписанию, ученикам, транскриптам и материалам.
- Обновлять данные при показе страницы и по таймеру.

### 3. Глобальная контекстная полоса

- Разместить под header компактную полосу текущего контекста.
- Показывать маршрут, ученика, дату, предмет, тему и состояние занятия.
- Показывать локальный или облачный режим LLM.
- Добавить кнопку обновления и быстрый переход к активному занятию.
- Синхронизировать текст с accessibility API.

### 4. Pipeline жизненного цикла занятия

Этапы:

1. подготовка;
2. запись;
3. транскрипция;
4. проверка;
5. материалы;
6. публикация.

Для каждого этапа:

- состояния `completed`, `active`, `attention`, `pending`;
- текстовый статус вместе с цветом;
- переход к соответствующему route;
- доступное объяснение текущего состояния;
- единое вычисление pipeline из `Lesson.status` и состояния LLM-нормализации.

### 5. Центр внимания и badges

- Ввести модель `AttentionItem` с severity, route, заголовком и пояснением.
- Показывать задачи, которые требуют действия преподавателя.
- Выводить количество событий у маршрутов sidebar.
- Добавить общий индикатор спокойного состояния.
- Исключить дублирование одинаковых событий.
- Ограничить список наиболее важными событиями.

### 6. Командная палитра `Ctrl+K`

Источники команд:

- все маршруты;
- быстрый урок;
- ученики;
- следующее занятие;
- диагностика;
- журнал;
- настройки LLM;
- обновление cockpit.

Требования:

- фильтрация по словам и подстрокам;
- управление стрелками, Enter и Escape;
- доступные названия;
- отображение сочетаний клавиш;
- выполнение команд через callbacks;
- защита от запуска отключённых команд.

### 7. Восстановление UI-сессии

Сохранять через `QSettings`:

- геометрию окна;
- последний подробный route;
- состояние sidebar;
- размеры splitter в материалах и карточках учеников;
- фильтры архива материалов;
- последний выбранный режим.

Правила:

- quick mode из конфигурации сохраняет приоритет при первом запуске;
- повреждённые или устаревшие значения игнорируются;
- восстановление выполняется после построения всех страниц;
- запись выполняется при закрытии окна и после значимых изменений.

### 8. Адаптивный sidebar

- Добавить полный и компактный режимы.
- В компактном режиме сохранять доступные названия и tooltips.
- Добавить кнопку сворачивания.
- Показывать badges в обоих режимах.
- Сохранять состояние между запусками.

## Архитектура

Новые модули:

- `ui/app_routes.py` — маршруты и реестр;
- `ui/teacher_cockpit.py` — dashboard, context bar, pipeline и attention;
- `ui/command_palette.py` — модель команд и диалог;
- `ui/ui_session.py` — сохранение и восстановление UI-состояния.

Изменяемые модули:

- `ui/information_architecture.py` — семантический sidebar и badges;
- `ui/transcript_publication_app.py` — установка UX-6 поверх production window;
- `ui/accessibility.py` — metadata новых управляющих элементов при необходимости;
- package metadata и README.

## Критерии готовности

- каждый sidebar item и команда `Ctrl+K` открывают корректный route;
- экран «Сегодня» работает при пустой базе и при наличии расписания;
- context bar корректно работает без активного занятия;
- pipeline всегда содержит шесть этапов и текстовое состояние;
- badges обновляются после refresh;
- закрытие и повторный запуск восстанавливают подробный route и геометрию;
- compact sidebar остаётся клавиатурно доступным;
- существующие восемь вкладок сохраняют legacy-индексы;
- полный production gate зелёный.
