# Benchmark: qwen3:8b и qwen3:14b

Репозиторий содержит воспроизводимый последовательный benchmark. Он не запускает
две модели одновременно и не публикует текст занятия:

```powershell
uv run python scripts/benchmark_normalization.py <lesson-id> `
  --models qwen3:8b qwen3:14b `
  --repeats 3 `
  --output .\normalization-benchmark.json
```

Сравниваются:

- полное время обработки;
- стабильность `retained_ratio`;
- число автоматических предупреждений;
- результаты ручной проверки golden-категорий;
- пиковое потребление RAM из Windows Task Manager.

Рекомендуемый протокол:

1. Один и тот же обезличенный транскрипт длиной 180–250 сегментов.
2. `temperature=0`, одинаковые `num_ctx`, chunking и prompt version.
3. Холодный запуск отдельно от трёх прогретых повторов.
4. Никакой параллельной Whisper-транскрибации.
5. Ручная проверка блокирующих ошибок: формула, число, вопрос/ошибка ученика,
   условие задачи и домашнее задание.

На машине с 32 ГБ DDR4 и CPU сначала следует принять `qwen3:8b` как рабочий
профиль. `qwen3:14b` — профиль повышенного качества, который нужно выбирать,
если измеренное время укладывается в рабочий процесс и golden-проверка даёт
существенно меньше ручных предупреждений. Численные результаты намеренно не
зафиксированы без запуска на целевом ноутбуке: скрипт создаёт их на реальном
оборудовании и исключает выдуманные показатели.
