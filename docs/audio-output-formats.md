# Итоговые форматы аудиозаписи

## Контракт

Tutor Assistant всегда записывает realtime-чанки в WAV PCM16. После завершения занятия приложение:

1. объединяет чанки микрофона и системного звука;
2. создаёт внутренний WAV-мастер `lesson.wav`;
3. проверяет качество дорожек;
4. формирует выбранный пользовательский файл;
5. проверяет кодек и длительность через FFprobe;
6. атомарно заменяет итоговый файл после успешной проверки.

WAV-мастер сохраняется при любых сбоях кодирования. Это позволяет повторить конвертацию без новой записи занятия.

## Доступные форматы

| Формат | Кодек | Параметры | Назначение |
|---|---|---:|---|
| M4A | AAC | 96 кбит/с | Значение по умолчанию; компактный архив уроков |
| MP3 | MP3 | 128 кбит/с | Максимальная совместимость с проигрывателями |
| WAV | PCM16 | без сжатия | Монтаж, диагностика и lossless-хранение |

M4A и MP3 требуют `ffmpeg` и `ffprobe` в `PATH`. WAV поддерживает встроенный потоковый mixer при отсутствии FFmpeg.

## GUI

Переключатель расположен в подробном режиме:

`Занятие → Параметры занятия → Итоговый формат аудио`

Выбор сохраняется в `config/app.yaml`:

```yaml
recording:
  output_format: m4a
```

Быстрый запуск использует последнее сохранённое значение. Переключатель блокируется на время активной записи.

## Session manifest

Новые сессии используют schema version 4 и сохраняют:

- `output_format`;
- `output_codec`;
- `output_encoder`;
- `output_bitrate_kbps`;
- `master_file`;
- `output_file`;
- `encoding_completed_at`.

Сессии прежних версий без `output_format` восстанавливаются в WAV. Это сохраняет совместимость существующего архива.

## Сценарии отказа

### FFmpeg или FFprobe отсутствует

Запуск M4A/MP3 блокируется до начала занятия с понятным сообщением об установке полного комплекта FFmpeg.

### Кодирование завершилось ошибкой

`session.json` получает статус `encoding_failed`, текст ошибки и путь к WAV-мастеру. WAV-мастер остаётся пригодным для транскрибации и повторного восстановления.

### Повреждённый итоговый файл

FFprobe обязан подтвердить ожидаемый кодек, наличие аудиопотока и положительную длительность. До успешной проверки временный файл не становится итоговым.

## Ручная проверка

1. Убедиться, что `ffmpeg -version` и `ffprobe -version` выполняются из PowerShell.
2. Выбрать M4A, записать короткое занятие и проверить `lesson.m4a` вместе с `lesson.wav`.
3. Повторить проверку для MP3 и WAV.
4. Открыть `session.json` и сверить формат, кодек, bitrate и имена файлов.
5. Временно убрать FFmpeg из `PATH` и проверить блокировку M4A/MP3 до старта.
6. Запустить recovery старой session version 3 и убедиться, что результатом становится WAV.
