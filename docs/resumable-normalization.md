
# Возобновляемая LLM-фильтрация

Нормализация транскрипта сохраняет результат каждого успешно проверенного блока в SQLite. После отмены, ошибки или перезапуска готовые блоки того же logical run повторно не отправляются модели.

## Гарантии

- completed checkpoint проверяется по SHA-256 перед использованием;
- изменение источника, модели, промпта, предметного профиля или chunking-конфигурации создаёт другой logical run;
- финальный текст собирается строго по `chunk_index`;
- ручное утверждение результата остаётся обязательным;
- текст занятия, prompt и ответы модели не записываются в журнал.

## Неопределённые облачные запросы

Hard crash во время запроса оставляет чанк в состоянии `running`. При следующем запуске он становится `indeterminate`.

- локальный Ollama может повторить такой блок автоматически;
- Yandex AI Studio требует явного подтверждения, потому что предыдущий запрос мог быть принят и тарифицирован;
- CLI использует флаг `--retry-indeterminate`.

Это effectively-once обработка для зафиксированных checkpoints, а не обещание exactly-once для внешнего API.
