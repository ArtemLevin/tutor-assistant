# Предметно-зависимая LLM-фильтрация

PR 32 переводит фильтрацию с математического словаря на предметные профили. Профиль
определяется автоматически из `Lesson.subject` и проходит через весь контур:
запрос к LLM, детерминированную валидацию, manifest, кэш запуска и окно проверки.

## Поддерживаемые профили

| Профиль | Типичные значения `Lesson.subject` | Версия промпта |
|---|---|---|
| `mathematics` | `mathematics`, `математика`, `алгебра`, `геометрия`, `ЕГЭ математика` | `educational-content-filter.mathematics.v2` |
| `physics` | `physics`, `физика`, `механика`, `электродинамика`, `ЕГЭ физика` | `educational-content-filter.physics.v1` |
| `chemistry` | `chemistry`, `химия`, `органическая химия`, `ЕГЭ химия` | `educational-content-filter.chemistry.v1` |
| `generic` | любой неизвестный предмет | `educational-content-filter.generic.v1` |

Сопоставление нечувствительно к регистру, `ё/е`, разделителям и составным названиям.
Неизвестный предмет не приводит к ошибке: применяется консервативный общий профиль.

## Что входит в профиль

Каждый профиль содержит:

- стабильный идентификатор и собственную версию промпта;
- русские и английские aliases;
- перечень тем школьной программы для системного промпта;
- детерминированные основы защищённых терминов;
- предметные единицы и обозначения;
- примеры характерных формул.

Математический профиль защищает, в частности, логарифмы, неравенства, ОДЗ,
производные, тригонометрию, геометрию и вероятность. Физический — кинематику,
законы Ньютона, импульс, энергию, термодинамику, электричество, оптику и единицы
СИ. Химический — строение вещества, реакции, количество вещества, растворы,
ОВР и классы органических соединений.

## Инварианты

Предметный профиль не разрешает модели исправлять текст. Валидация по-прежнему
требует, чтобы результат был токенной подпоследовательностью исходного
транскрипта. Дополнительно запрещено удалять:

- защищённые термины выбранного профиля;
- предметные единицы измерения;
- формульный фрагмент целиком;
- вопросы, ошибки и сомнения ученика;
- домашнее задание и учебные указания.

Предмет и версия профиля включаются в configuration hash. Поэтому одинаковый
транскрипт, обработанный как физика и как общий предмет, не переиспользует один
и тот же результат.

## Manifest

`normalization_manifest.json` содержит:

```json
{
  "lesson_subject": "ЕГЭ физика",
  "subject_profile": "physics",
  "prompt_version": "educational-content-filter.physics.v1"
}
```

Старые manifests без этих полей продолжают читаться через значения по умолчанию
`generic`.

## Регрессионный набор

`tests/fixtures/subject_filter_cases.json` содержит эталонные фрагменты по
математике, физике, химии и общему профилю. Тесты проверяют допустимое удаление
технических реплик и запрет потери предметного содержания.
