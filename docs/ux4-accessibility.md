# UX-4: доступность

Цель PR — обеспечить видимый фокус, клавиатурную навигацию, полные accessible names, текстовые статусы и проверяемую устойчивость интерфейса к Windows scaling.

## Контракты

- основные сценарии доступны через клавиатуру;
- каждый ключевой интерактивный элемент имеет осмысленное доступное имя;
- цветовые состояния сопровождаются текстом;
- Tab order соответствует визуальному порядку;
- интерфейс проходит focused-проверки при масштабах Windows 100%, 125%, 150% и 200%.
