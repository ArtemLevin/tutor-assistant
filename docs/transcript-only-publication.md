# Публикация только подтверждённого транскрипта

## Назначение

После ручного подтверждения преподавателем Tutor Assistant может передать в репозиторий ученика ровно один файл:

```text
<student.repository_folder>/lessons/<lesson_slug>/transcript.txt
```

Целевая ветка зафиксирована как `main`. Аудиозаписи, раздельные дорожки, чанки, `lesson.json`, `job.status.json`, сегменты, manifest, сигналы ученика, TEX, PDF, изображения, отчёты и журналы остаются в локальном workspace.

## Условия публикации

Публикация разрешается при одновременном выполнении условий:

1. занятие находится в статусе `ready_for_generation`, полученном после ручного подтверждения текста;
2. `artifacts.verified_transcript` указывает на существующий UTF-8 файл;
3. целевой репозиторий доступен локально;
4. перед отправкой в GitHub подтверждена приватность репозитория;
5. staged diff и полный outgoing diff содержат только ожидаемый `transcript.txt`.

Любое отклонение блокирует операцию до выполнения `git push`.

## Git-поведение

Publisher получает актуальный `origin/main`, создаёт изолированный detached worktree либо использует чистую основную копию, атомарно записывает `transcript.txt`, фиксирует commit и отправляет `HEAD` непосредственно в `main`.

Отдельная lesson-ветка и draft PR для публикации учебных данных больше не создаются. Настройка `repository.auto_create_pr` сохраняется в конфигурационной модели для совместимости старых файлов и не участвует в transcript-only workflow.

Повтор после сетевого сбоя идемпотентен. Перед повторным push снова проверяется полный набор исходящих путей.

## Граница удалённого LaTeX-контура

`PublicationInfo.repository_path` хранит путь к самому `transcript.txt`. Удалённый LaTeX-monitor ожидает каталог с `handbook/*.tex`; для transcript-only публикации такой кандидат отсутствует. Поэтому последующие JSON, TEX, PDF, preview и отчёты через этот контур не отправляются.

## Проверки

Regression-набор закрепляет следующие инварианты:

- payload содержит один путь;
- имя файла всегда `transcript.txt`;
- ветка всегда `main`;
- публикация до ручного подтверждения отклоняется;
- отсутствующий и не-UTF-8 транскрипт отклоняется;
- staged/outgoing diff с любым дополнительным путём отклоняется;
- retry после временной ошибки push публикует только подтверждённый текст.
